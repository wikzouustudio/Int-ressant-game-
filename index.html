Comment jouer

Sur ordinateur

  • ZQSD ou WASD pour bouger
  • Clic gauche pour attaquer vers la souris
  • Clic droit (maintenir pour viser) ou Espace pour le super
  • Échap pour la pause

Sur mobile

  • Joystick à gauche pour bouger
  • Bouton orange : touche pour viser automatiquement, glisse pour viser à la main
  • Bouton jaune : le super, dès qu'il est chargé

Règles

  • 3 munitions qui se rechargent toutes seules
  • Toucher un ennemi charge ton super
  • Sans combat pendant 3 s, tu régénères tes PV
  • Les buissons te cachent, sauf si un ennemi est tout proche

Modes

  • K.O. Express : la première équipe à 10 K.O. gagne
  • Zone Chaude : restez seuls dans le cercle central pour remplir votre jauge
